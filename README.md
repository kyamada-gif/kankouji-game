# 現場まるわかり（試作）

管工事の施工管理として入社する新卒向けの、建設現場の全体像を学ぶインタラクティブ教材のプロトタイプ。

- 実装済み：**B. 危険探し**（7段階 × 2〜3件）
- 未実装：A. 職種マップ / C. 搬入・搬出（ボタンのみ）

## 起動

```sh
npm install
npm run dev
```

## 構成

| パス | 内容 |
|---|---|
| `src/data/stages.ts` | 工期7段階。`image` を入れると背景を画像に差し替え |
| `src/data/hazards.ts` | 危険の位置と解説（※仮の文言を含む） |
| `src/data/response.ts` | 対応の手順・誰に言うかの見分け方（共通） |
| `src/scene/` | 断面図の SVG（建物・機械・人物） |
| `src/components/` | 断面図の操作、解説パネル、工期スライダー、位置編集 |
| `docs/image-prompts.md` | 画像生成AI用のプロンプトと差し替え手順 |

安全ルール・法令の数値は、専門家の確認前の仮の内容です。
